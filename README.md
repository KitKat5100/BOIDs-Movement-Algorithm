# BOIDs-Movement-Algorithm
A 3rd year self-directed research project. Replicates the BOIDS algorithm: a crowd movement algorithm developed by Craig Reynolds, and applies it to fishlike objects with raycast-based collision avoidance. 
The result is a unity executable that spawns numerous fish and has them move and crowd together in swarms in accordance with the algorithm. Various parameters can be adjusted to change their movement

The bulk of the algorithm is contained within Final Project - BOIDS/Assets/Scripts/BOID.cs

# Running the executable
- Clone the repository
- under the Executable folder, run "BOIDS Fish Simulation.exe"
